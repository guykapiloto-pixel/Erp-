# מנוע חישוב מס ללקוחות (יחידים וחברות)

חישוב מס הכנסה, מס חברות, ס' 62א (תיקון 277), ס' 81א–81ו, ביטוח לאומי, מקדמות ותרחישי משכורת/דיבידנד לשנות המס 2025–2026, עם פירוק מלא של כל מספר לנוסחה ולמקור החוקי.

- `engine/` – ספריית החישוב (Python, Decimal, פרמטרים לפי שנה ב-YAML, בדיקות זהב מול דוגמאות רשות המסים)
- `api/` – FastAPI: חישוב, היסטוריה, לקוחות שמורים, ייצוא Excel, תרחישים, הוראת שעה
- `web/` – ממשק React בעברית (RTL)
- `crm/` – שכבת חיבור ל-CRM (מימוש בדיקה מבוסס קבצים)
- `debt_agent/` – סוכן בדיקת חובות לקוחות מלוח monday "יעל EK-גבייה" (ראו `debt_agent/README.md`)
- `docs/` – מסמך לוגיקה, הערות מימוש ומקורות

הוראות הרצה: `docs/02-implementation-notes.md`.
